BEFORE PUBLISHING
1. Replace YOUR_EMAIL_HERE inside index.html with your real email.
2. Add your resume PDF to this same folder and name it resume.pdf.
3. Replace the placeholder Writing links (#) with links to your published articles.
4. You can replace any text, project descriptions, or YouTube links inside index.html.

FREE PUBLISHING WITH GITHUB PAGES

1. Go to github.com and create a free account if needed.
2. Click New Repository.
3. Name it something like:
   daniel-suarez-portfolio
4. Make the repository Public.
5. Create the repository.
6. Upload index.html, style.css, script.js, and resume.pdf.
7. Open the repository Settings.
8. Click Pages in the left menu.
9. Under Build and deployment, choose:
   Source: Deploy from a branch
   Branch: main
   Folder: /root
10. Click Save.

GitHub will generate your free website address, normally:
https://YOUR-GITHUB-USERNAME.github.io/daniel-suarez-portfolio/

You can later buy a custom domain such as danielsuarezmedia.com and connect it, but this is optional.
